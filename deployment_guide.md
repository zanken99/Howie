# Инструкция по деплою на Vercel

Чтобы ваш проект HowieCheats корректно работал на Vercel с вашим собственным доменом, следуйте этой инструкции.

## 1. Подготовка репозитория (GitHub)

В ваш GitHub репозиторий **должны** попасть следующие папки и файлы:
- `src/` — исходный код приложения.
- `public/` — статические файлы (картинки, фавиконы).
- `package.json` и `package-lock.json` — зависимости и скрипты.
- `next.config.mjs` — настройки Next.js.
- `tsconfig.json` — настройки TypeScript.
- `postcss.config.mjs` и `tailwind.config.ts` (если есть) — настройки стилей.
- `.gitignore` — **ВАЖНО!** Я уже создал этот файл для вас. Он гарантирует, что вы не загрузите лишние файлы (например, `node_modules` или секреты).

### Как загрузить в GitHub:
1. **Создайте новый репозиторий** на [GitHub](https://github.com/new).
2. Скопируйте ссылку на ваш репозиторий (она выглядит как `https://github.com/ваш-логин/ваш-репо.git`).
3. В папке проекта выполните команды (вставляйте по одной, заменяя ССЫЛКУ на кусок из шага 2):
   ```bash
   git remote remove origin
   git remote add origin ССЫЛКА_ИЗ_GITHUB
   git push -u origin main --force
   ```

> [!IMPORTANT]
> При копировании команд из блоков выше **не копируйте** первую строку ` ```bash ` и последнюю ` ``` `. Это просто маркеры кода.
> Также обязательно замените `ССЫЛКА_ИЗ_GITHUB` на реальную ссылку вашего репозитория.

## 2. Импорт в Vercel

1. Зайдите на [vercel.com](https://vercel.com) и войдите через GitHub.
2. Нажмите **"Add New"** -> **"Project"**.
3. Выберите ваш репозиторий HowieCheats и нажмите **"Import"**.
4. В разделе **"Build & Development Settings"** Vercel автоматически определит Next.js. Ничего менять не нужно.
5. Если у вас есть секретные ключи или пароли, добавьте их в разделе **"Environment Variables"**.
6. Нажмите **"Deploy"**.

## 3. Подключение домена

1. После успешного деплоя перейдите в настройки проекта в Vercel: **Settings** -> **Domains**.
2. Введите ваш купленный домен (например, `howiecheats.com`) и нажмите **"Add"**.
3. Vercel предложит вам добавить записи (A или CNAME) в панели управления вашего регистратора домена.
4. Следуйте инструкциям Vercel. Обычно это создание `A` записи на IP адрес Vercel или `CNAME` на `cname.vercel-dns.com`.

---
**Совет:** Не загружайте папку `.next`, `node_modules` и `out`. Vercel сам соберет проект из исходников при каждом обновлении в GitHub.
